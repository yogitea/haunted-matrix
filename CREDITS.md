# Credits and artwork provenance

## Code and bundled pictures

Haunted Matrix was developed with AI assistance. The 99 bundled illustrations
were created with OpenAI image generation, then prepared for a 64×32 LED matrix.
The original prompts are recorded in [ARTWORK-PROMPTS.md](ARTWORK-PROMPTS.md).
Editing sources and ready-to-view BMPs are included under `artwork/`.

The project code and bundled assets are made available under the repository's
MIT license to the extent applicable rights are held by the contributors.

## Original howling-wolf bitmap — not included

The optional `/moon/splash-0.bmp` originates from Adafruit's
[Moon Phase Clock for Adafruit Matrix Portal](https://learn.adafruit.com/moon-phase-clock-for-adafruit-matrixportal).
That project's original code credits Lew Lashmit for the landscape splash
artwork and asks that splash images not be included in derivative projects.

No original Adafruit splash image, moon-phase asset, clock source, font or
third-party library is distributed here. The optional loader only supports
artwork that users already possess and are entitled to use. The MIT license
in this repository does not grant rights to those third-party images.

## Hardware and runtime

MatrixPortal and CircuitPython are Adafruit projects. Adafruit's documentation
informed the HUB75 pin setup. This is an independent project, without Adafruit
or OpenAI sponsorship or endorsement.

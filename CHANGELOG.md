# Changelog

## 1.0.0 — 2026-10-27

- Initial standalone release for MatrixPortal M4 and 64×32 HUB75 panels.
- 99 detailed generated horror illustrations in a compact offline gallery.
- Shuffled rounds without adjacent picture repeats.
- Whole-picture fade out through black and smooth fade in.
- Coherent color-region dimming, up to 70%, with two slow cycles per hold.
- Optional user-supplied howling-wolf bitmap, excluded from distribution.
- Hardware validation on CircuitPython 7.0.0, desktop tests, CI and install ZIP.
